## Xenobiotic enzymes contribute significantly to human steroid metabolome 

This is the repository for data analysis in:
Zheng, Yu and Li. Xenobiotic enzymes contribute significantly to human steroid metabolome. 

Input data include the main feature tables. 
Feature tables from time course, liver microsome experiments and public data can be generated using Asari with the version and parameters stated in the paper. 

All analysis notebooks are in code repository.
Input data and the analysis output is posted as a release of this repository. 

## Data and Code Availability: 	
The metabolomics data are on Metabolomics Workbench (https://www.metabolomicsworkbench.org) under the studies ST005297, project DOI: https://dx.doi.org/10.21228/M8D50FX57; ST005298, project DOI: https://dx.doi.org/10.21228/M8D50FX57; ST005299, project DOI: https://dx.doi.org/10.21228/M8D50FX57; ST005300, project DOI: https://dx.doi.org/10.21228/M8D50FX57. The public datasets used here are ST003324, ST003325, ST003940 and ST003952. 

All software code for data analysis in this work is provided at https://github.com/shuzhao-li-lab/Zheng2026_steroids.
