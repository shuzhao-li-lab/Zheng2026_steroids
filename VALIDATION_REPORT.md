# Reproducibility validation: v9_b notebooks

**Date:** 2026-11-22

## Summary

All 11 notebooks ran start to finish with no errors and no manual steps. Every regenerated output either matches the existing `results/` exactly or differs only in harmless ways: rows in a different order, or floating-point noise around 1e-13.

## Method

1. Built a fresh Python environment (versions below).
2. Made an isolated run directory. It linked to `input/` read-only, held copies of the notebooks, and started with an empty `results/` tree. The original `results/` was not modified.
3. Ran the notebooks in order with `jupyter nbconvert --execute`: 1, 2, 3, 3b, 3c, 4, 5a, 5b, 5c, 5d, 6. Each step read only what earlier steps had regenerated.
4. Compared every regenerated file with the original:
   - **Byte-identical:** same MD5 checksum.
   - **TSV/CSV:** same shape and columns. Numeric values agree within a relative tolerance of 1e-6. If values differed, the files were also compared ignoring row order.
   - **JSON:** same structure, with floats rounded to 6 decimals. If that failed, the files were also compared ignoring list order.
   - **XLSX:** same content on every sheet.
   - **PDF:** rasterized and compared pixel by pixel.
